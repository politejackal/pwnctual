C syntax

Here is an example of C code:

C#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}

I know that looks very cryptic at first. But it's one of the simplest programs possible out there.

Now the first line is something we will come back to in a bit. The main aim of this lesson is to teach you the basic grammar of the C language.

You should, for now, also ignore what int means.

See that main? It is just the name of the function. Recall that a function is a bunch of code that performs specific actions. Now how does the program know that you are defining a function, or perhaps defining a variable (recall a variable is like a container that stores something, like some value)? Well, you use a pair of parentheses, (), to say that this is a function and not a variable or something else.

Then, inside a pair of curly braces, {}, you write whatever you want that specific function to do. Think of curly braces as the walls, and whatever is inside those walls is what happens whenever that function runs.

Now printf is just a function like main, written by somebody else. How does the program know where it is—I mean, there is nothing defined for it, right? Well, the first line is what imported it. The line starting with a # is a special line used for importing things. We imported a file called stdio.h, which stands for standard input/output. .h is just a label saying it's a header file, but don't worry about that now.

Now also notice that some lines end with a semicolon, ;. Well, it turns out every instruction in C, except for function definitions and #include lines, needs to end with a semicolon. There is no need to write different instructions on different lines—you could just separate almost all instructions with semicolons and it would work the same. It turns out that this code does the exact same thing:

C#include <stdio.h>
int main(){printf("Hello, World!"); return 0;}

Remember that everything is case-sensitive here, and typos will almost certainly stop your program from compiling ( we will learn this soon). Anyway, that was our first C program!
