Understanding Binary: Ones and Zeroes

Computers are all about ones and zeroes. But what actually are these ones and zeroes?

Well, you see, deep inside your device, all there is are a bunch of tiny switches called transistors. And by a bunch, I mean billions of them. A switch can only have two states: it can either be on or off. Nothing else.

It turns out we can represent all kinds of things by creating patterns with these switches. Instead of saying "off" and "on" every time, we shorten it and call it 0 for off, and 1 for on. In computer science terms, a single switch—either on or off—is called a bit. Cool.

Switch StateBit Value
ON1
OFF0

Now, a single zero or one on its own is pretty useless. They only start making sense when we group a sequence of these switches together to represent something—and from that, we can represent many things, and so on. This is where the magic of computing happens.

For example, we can represent a row of switches like this: 01000100. Here, wherever you see a 0, it means a switch is turned off. Whenever you see a 1, it means a switch is turned on.

Before we go any further, we need to understand the computer's number system, because it is pretty surprising that you can build an entire number system using just ones and zeroes.

How Our Normal Number System Works

Before we jump into how computers count, let's recall our normal, everyday number system from school (decimal). Here, we have 10 digits: 0 through 9.

Take a number like 1234. Starting from the right:

  1. We multiply the 4 by 1.
  2. Move one spot to the left, multiply the 3 by 10, and add them together: (10 × 3) + (1 × 4).
  3. Move left again and add the 2 multiplied by 100: (100 × 2) + (10 × 3) + (1 × 4), and so on.

That is just so you get the idea: every time you move one place to the left, the place value gets multiplied by 10. Here is another example using the number 101:

How the Computer's Number System (Binary) Works

Now, in the computer's number system (called binary), instead of multiplying each place value by 10 as we move to the left, we multiply it by 2.

If you had a longer binary number, like 1010, the leftmost 1 would be in the 8's place (4 × 2), and so on. It is as simple as that. And that is how bigger numbers are stored: by using more bits.
