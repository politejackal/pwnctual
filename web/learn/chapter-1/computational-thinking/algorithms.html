Algorithms are nothing but a set of instructions, like a recipe for a cake.

A recipe for a cake

  1. Heat the oven.
  2. Mix the flour, sugar and eggs in a bowl.
  3. Pour the mix into a pan.
  4. Bake it for 30 minutes.
  5. Take it out and let it cool.

An algorithm to find John's number

  1. Start at the first name in the contacts.
  2. Compare the name with the text "John".
  3. If it is equal, hand out the phone number.
  4. If not, move to the next name.
  5. Go back to step 2.

An example of an algorithm is an algorithm to search for John's number in your contacts. Now you can write an algorithm in many ways. You could just go step by step, look at each name, and compare it with the text "John", and if it is equal, you find his phone number and hand it out. This might seem like a simple, cool little program—easy to work with, but way too dumb and inefficient. As hackers are also programmers, I believe, and you should believe too, that as programmers it's our job to write code that is efficient and fast and does fewer calculations.

Now assume a scenario where the names are alphabetically sorted, as is the case generally. Now instead of going and checking every single name, you just go to the middle of the names and check if the name is on that page. If not, then you check if the name is to the right of where you are now or to the left, because the names are alphabetically sorted. You then throw the other half where you know the name is not. You keep only the half that can still contain the name. Now you have reduced the problem size in half. Then you again go to the middle of the middle, and then to the middle of the middle of the middle, and so on, until you find the name.

But we are missing something. We forgot to add a final touch to our algorithm. And if we had not remembered this now, we would expose our program to a huge bunch of attacks and stuff, and we don't want that to happen—with our program, at least. The thing is, we forgot to give the program the instruction to quit after finding John's number. Not specifying this can cause our program to misbehave in many ways!
