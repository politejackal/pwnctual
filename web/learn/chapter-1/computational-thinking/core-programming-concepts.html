By the way, we won't be learning programming languages like "such and such does such and such." Instead, we will be learning the fundamental concepts of how programming languages work, so you can understand any language if you ever have to learn another one in the future.

So before we start learning any programming languages, we need to understand the basic concepts of how these languages work inside the computer. We will be starting with C, as it is a low-level programming language, and a good place to start for beginners, then we will learn Python, and then we will learn Assembly.

Before touching any programming languages, know that all languages generally have the following things to communicate with the device and do something useful:

  • Variables: Containers that store something, i.e., some value.
  • Conditions (if/else): Making the program make decisions based on something.
  • Loops: Repeating something as many times as you want without rewriting the code every time.
  • Functions: A bunch of code that performs specific actions.
