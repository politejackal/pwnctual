Some important stuff before you go ahead

A byte is an 8-digit long binary number, like 01001001. It consists of 8 bits. The lowest value you get is 00000000, which is 0, and the maximum value you get is 11111111, which is 255 if you add up all the place values. So a byte can store values anywhere from 0 to 255, which is 256 possible values including the 0. Remember this, we will be using this a lot.

How everything you see is zeroes and ones

Everything you see on your screen is just a bunch of zeroes and ones. Who said? Well, you see, your device screen has millions of pixels. Each pixel has 3 tiny light bulbs: red, green, and blue. We give each bulb an intensity from 0 to 255—recall that this is the value that can be stored in a byte. So we give each bulb—red, green, and blue—an intensity, and it makes that amount of light visible, which gives us the colors we want, and hence the screen you are looking at. So now you should understand what we mean by these ones and zeroes. Similarly, all images, videos, passwords, etc., are all just ones and zeroes.

Now similarly, we humans have also come up with something to represent text. We represent each character with a bunch of zeroes and ones (this is known as ASCII, we will come back to this).
