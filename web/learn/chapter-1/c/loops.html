In your hacking journey, many times you will be in a situation where you want to do something multiple times. For this, we have something called loops. You can copy-paste the same code, but that's bad design for many reasons, which is why we have loops. So a loop just repeats a block of code, either an infinite or a finite number of times.

In C, we have two main types of loops, as we do in almost all programming languages: while loops and for loops.

The while Loop

A while loop keeps repeating a block of code as long as a given condition is true. If that condition never becomes false, it will repeat an infinite number of times (an infinite loop). Usually, we change something inside the loop so it eventually stops:

int count = 0;

while (count < 3) {
    printf("Trying password... attempt %d\n", count);
    count = count + 1;
}

Here, the loop runs as long as count is less than 3. Each time it runs, count goes up by 1, so after 3 tries the condition becomes false and the loop stops.

The for Loop

A for loop is usually used when you know the exact, finite number of times you want something to run. In C, a for loop still uses a condition—it just packs the starting point, the condition, and the update step all into one neat line:

for (int i = 0; i < 5; i++) {
    printf("Scanning port %d\n", i);
}

(Quick tip: i++ is just a shortcut for i = i + 1.)

break and continue

Now, if you are in a loop, there is of course a way to get out of it early. You can use the break statement, which immediately quits the loop it is called from:

for (int i = 0; i < 10; i++) {
    if (i == 4) {
        printf("Found it! Stopping early.\n");
        break;
    }
    printf("Checking %d...\n", i);
}

Even though the loop is supposed to run up to 10, as soon as i hits 4, break kicks us straight out of the loop.

There is another keyword called continue, which just skips the remaining steps of that specific iteration and goes straight to the next one:

for (int i = 0; i < 5; i++) {
    if (i == 2) {
        continue; // Skip 2 and move straight to 3
    }
    printf("Number: %d\n", i);
}

This prints 0, 1, 3, and 4—completely skipping 2 without quitting the whole loop.

Loops inside loops

You can put a loop inside another loop. The inner loop runs all the way through every single time the outer loop runs once. For example, this prints a 3 by 4 rectangle of #:

for (int row = 0; row < 3; row++) {
    for (int col = 0; col < 4; col++) {
        printf("#");
    }
    printf("\n");
}

The outer loop goes through the 3 rows. For every row, the inner loop prints 4 #s, and then we print a \n to start the next row.

Watch Out for Off-by-One Errors

Miscalculating the starting or ending point of a loop can cause off-by-one errors, which can cause major problems—as they have many times in history!

For example, if you want a loop to run 5 times starting from 0:

// Runs 5 times (0, 1, 2, 3, 4) -> Correct!
for (int i = 0; i < 5; i++) { ... }

// Runs 6 times (0, 1, 2, 3, 4, 5) -> Off-by-one error!
for (int i = 0; i <= 5; i++) { ... }

When we get to arrays and memory later, running a loop just one extra time can accidentally overwrite neighboring memory—which is how real vulnerabilities are born.
