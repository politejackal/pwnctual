Now of course, you can store stuff in programming. For example, you can store the value 1337 in x by saying int x = 1337;. Now here, int is just short for integer, and it is important for you to specify the type of the variable before assigning the value to it. This is all a bit of a headache, which is why in the next module we will transition from C to Python, where Python does this assigning of the value type for us.

So in C, we specify the type of the variable before assigning the value. This is done by simply typing the type of the variable you are assigning before the name of the variable. The name could be whatever you want, but there are some rules to follow.

There are 4 main types of variables in C. These are int, char, float, and double:

  • int (short for integer, 4 bytes long): Stores whole numbers without decimals. Example: int age = 25;
  • char (short for character, 1 byte long): Stores a single character or an ASCII value. Example: char grade = 'A';
  • float (floating-point number, 4 bytes long): Stores decimal numbers with precision for about 6–7 digits. Example: float pi = 3.1415927;
  • double (8 bytes long): Stores decimal numbers with double precision, about 15 digits long. Example: double pi = 3.14159265358979;

The printf function allows printing variables, but as you know, the meaning of printf itself is "print formatted", so you need to format the type of the variable and some more things. Let's look at an example.

Say I wanted to print a number x, whose type is int, I would need to use a percentage symbol and an i such as follows:
printf("%i");

I would then, after the second double quote, put a comma and type the name of the variable I am printing:
printf("%i", x);

Of course, before running this command, you would need to specify x with something like int x = 1337;.

Before we look at the other types, you might notice a \n in the examples below. \n is just a special, invisible character that tells the terminal to hit "Enter" and start a new line. If you don't use it, your next terminal prompt will be squished right next to your output, looking all messy.

Just like the %i is for int, here are the different specifiers for different variable types:

Data TypeSpecifierExample Code
int (Integer)%d or %iprintf("%d\n", x);
float (Decimal)%fprintf("%f\n", x);
double (Large Decimal)%lf or %fprintf("%lf\n", x);
char (Single Character)%cprintf("%c\n", x);

Now, you might be thinking, "Wait, if a char only holds one single letter, how do I store a whole word or a sentence?"

Well, it turns out C is so low-level that it doesn't actually have a "string" (word) variable type! If you want to store a word, you have to use a bunch of chars lined up next to each other. We will dive into how that works very soon, but for now, just know that when you do want to print a word or text, you use the %s specifier.
