Conditionals are like the basic decisions we make when we want to do something. For example, "if it is raining, I will take the umbrella."

Conditionals allow you to do specific things based on whether some statements are true or false. In C, true is represented by any value other than 0, and false is represented by a 0. Yes, plain numbers have true/false meanings in C!

In C, relational and equality operators compare two values and look for their relationship. If the statement is true, C gives us 1, and if it is false, it gives us 0.

The operators we have in C are:

  • Equal to (==)
  • Not equal to (!=)
  • Greater than (>)
  • Less than (<)
  • Greater than or equal to (>=)
  • Less than or equal to (<=)

The use of these operators is simple. You just type a variable on the left-hand side and the right-hand side and add the symbols in between. For example:

10 > 5   // This gives us 1 (True)
10 <= 5  // This gives us 0 (False)

Remember that we assign a value with a single equal sign (=), but when we want to check for equality, we use a double equal sign (==). For example:

int x = 5;  // This ASSIGNS the value 5 to x.
x == 5;     // This CHECKS if x is equal to 5 (returns 1 for True).

Note: Mixing up = and == inside a condition is one of the most common ways programmers accidentally introduce massive bugs and security vulnerabilities!

The Core Statements

  • if statement: Does something if the following condition is true.
  • else if statement: Does something if the previous if statement was false AND this new condition is true.
  • else statement: Executes only when ALL the prior if and else if statements are false.

You can branch as many statements as you like. For example:

int age = 15;

if (age < 13) {
    printf("You are a kid.\n");
}
else if (age < 18) {
    printf("You are a teenager.\n");
}
else {
    printf("You are an adult.\n");
}

(Since age is 15, the first statement is false, but the second statement is true, so it will print "You are a teenager.")

Logical Operators (AND, OR, NOT)

Now we have Logical operators. In C, we don't type the English words; we use special symbols: && (AND), || (OR), and ! (NOT).

AND (&&) just means the condition on the left-hand side as well as the right-hand side must BOTH be true. Otherwise, the whole statement is false.

// Checking if a number is between 10 and 20
if (x > 10 && x < 20) {
    printf("x is right in the sweet spot!\n");
}

OR (||) checks if the condition on either the left-hand side or the right-hand side is true. If any one is true, the whole statement is true.

// Checking if today is the weekend (Saturday is day 6, Sunday is day 7)
if (day == 6 || day == 7) {
    printf("It is the weekend!\n");
}

NOT (!) is the exact opposite of whatever follows it. If something is true, NOT makes it false.

int is_raining = 0; // 0 means false

if (!is_raining) {
    printf("It is NOT raining, leave the umbrella.\n");
}

Remember, the order of the conditions matters a lot, as you will see in the following challenges!
