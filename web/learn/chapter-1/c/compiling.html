Now who said the CPU can understand whatever was written in the script from the previous lesson? The CPU doesn't have any clue about what that means. Recall that all the CPU knows is ones and zeroes. But what we wrote are not ones and zeroes, so the computer can't understand it.

Well, it turns out that the C language we wrote is nothing but some words standing in for a bunch of ones and zeroes. We need some way to convert these words back to their respective zeroes and ones. This is where a tool called make comes in.

make uses something called a compiler. And a compiler is nothing but a translator which translates human-readable words into computer-executable instructions. Its job is to turn our C code into those machine instructions. The usage of make is quite simple, but before we learn about it, we should know something.

NOTE: It is a good practice to save any code written in C with the filename ending with .c. The .c is nothing but a label for us and others to know that the file contains C code. This is also important for compilers.

So the usage of make is simple. You just type make followed by the name of the .c file that you want to compile. You don't need to type .c when passing the name of the file as the argument—make will automatically find the file ending with .c and know we are talking about that file. It will then give you a new executable file with that exact same name. To run the file that make gives you, use ./ followed by the filename (for example, ./program).
