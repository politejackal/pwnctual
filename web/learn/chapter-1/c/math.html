Now of course, you can do calculations using C! Computers are, after all, giant calculators.

The basic arithmetic operators

There are 5 main arithmetic operators in C:

OperatorWhat it doesExampleResult
+Addition5 + 27
-Subtraction5 - 23
*Multiplication5 * 210
/Division5 / 22 (wait, what? We'll get to that)
%Modulus5 % 21

Notice that multiplication uses * and not ×, simply because there is no × key on your keyboard.

You can use these with variables too, and store the result in another variable:

int a = 5;
int b = 2;
int sum = a + b;
printf("%d\n", sum); // prints 7

The modulus operator

This operator is special and needs its own explanation. Unlike normal division, which gives you a quotient and a remainder, this operator does the division and just gives you the remainder. The operator to use for this is %. You use it like 5 % 2, and the result is 1, because 5 divided by 2 is 2, with 1 left over.

This might look useless, but it's actually genius. For example:

  • Checking if a number is even: if x % 2 == 0, then x is even, because even numbers leave nothing behind when divided by 2.
  • Getting the last digit of a number: 1337 % 10 is 7.
  • Wrapping around: on a 24-hour clock, (hour + 5) % 24 gives you the hour 5 hours from now, even if it goes past midnight.

And don't mix it up with the % inside printf, like %d. That one is a specifier, which just tells printf what to print. Same symbol, completely different job.

Dividing two integers

One important thing in C is how it handles the division of two integers. The result is always an integer. C just removes all the digits after the decimal point. It doesn't round it or anything, it just makes them disappear. So 5 / 2 gives you 2, and even 9 / 10 gives you 0!

NOTE: Never divide an integer by 0, and never use % 0 either. There is no answer to it, so your program will just crash.

Shortcuts

Instead of writing x = x + 1, there is a shortcut: x++. It does the exact same thing. Same with x--, which is a shortcut for x = x - 1.

And if you want to add something other than 1, there's a shortcut for that too: x += 5 is the same as x = x + 5. This works with all of them: -=, *=, /= and %=.

Type casting

Remember that 5 / 2 gives you 2 instead of 2.5? That's because both of them are integers, so C removes the .5. But if any one of the operands is a float, the result is a float too. So instead of 5 / 2, we can write 5.0 / 2, 5 / 2.0, or 5.0 / 2.0, and get 2.5.

But sometimes we are working with variables, and we can't just stick a .0 at the end of them. This is where type casting comes in. Type casting changes a value from one type to another, like an int to a float. You just write the name of the type you want in brackets, right before the value:

int a = 5;
int b = 2;
float result = (float)a / b;
printf("%f\n", result); // prints 2.500000

(float)a turns a into 5.0, so the division becomes 5.0 / 2, and the answer is 2.5. Casting generally only works for things that make sense, like turning one kind of number into another.

Careful though, where you put the cast matters: (float)(a / b) gives you 2.000000, not 2.5! The brackets make the division happen first, between two integers, so the .5 is already gone before the cast even happens.

Order of operations

Just like in school math, C doesn't simply go from left to right. *, / and % are done before + and -. So 2 + 3 * 4 is 14, not 20. If you want the addition to happen first, use brackets: (2 + 3) * 4 is 20. When in doubt, just use brackets. It also makes your code easier to read.
