Computers are all about ones and zeroes. But what are these ones and zeroes? Well, you see, deep inside your device, all there is are a bunch of tiny switches called transistors. And by a bunch I mean billions of them. So a switch can have only 2 states. A switch can either be on or off. Nothing else. It turns out we represent different things by some patterns, which in turn are created with a bunch of these switches. So instead of saying off and on every time, we shorten it and call it 0 for off, and 1 for on. This switch, either on or off, is called a bit in computer science terms. Cool.

Now, these zeroes and ones alone are useless. They make sense when we use a sequence of those switches to represent something, and from something we represent many things, and so on. This is where the magic of computing happens.

Now we can represent a bunch of switches as 01000100, and here wherever there is a zero, it means a switch that is turned off. And when we see a 1 it represents a switch that is on. Now before we go further, we need to understand the computer's number system, because it's surprising that there is actually a number system made of just ones and zeroes.

Before we go to understand the computer's number system, recall our normal everyday number system from school. Here we have 10 digits, 0 to 9. In this system, we do the following:

If we have a number like 1234, we multiply the 4 by 1, and add to it 3 multiplied by 10. Like (10 × 3) + (1 × 4). Then you add 2 multiplied by a hundred, like (100 × 2) + (10 × 3) + (1 × 4), and so on. This is just so you get the idea. Here is another example: 101

Now in the computer's number system, instead of multiplying each digit place to the left by 10, we multiply it by 2. I know you didn't understand a thing, so let's slow down and look at what I mean.

I used the number 101 for simplification because both number systems have it. But in binary remember you only have zeroes and ones!

If you had a longer number, like 1010, the first 1's place would be the 8's place, and so on. It's just as simple as that. And that's how bigger numbers are stored: more bits are used.

So now you know how to read a binary number.
