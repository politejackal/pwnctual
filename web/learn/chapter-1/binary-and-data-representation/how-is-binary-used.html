Some important stuff before you go ahead

A byte is an 8-digit long binary number, like 01001001. It consists of 8 bits. The lowest value you get is 00000000, which is 0, and the maximum value you get is 11111111, which is 255 if you add up all the place values. So a byte can store values anywhere from 0 to 255, which is 256 possible values including the 0. Remember this, we will be using this a lot.

How everything you see is zeroes and ones

Everything you see on your screen is just a bunch of zeroes and ones. Who said? Well, you see, your device screen has millions of pixels. Each pixel has 3 tiny light bulbs: red, green, and blue. We give each bulb an intensity from 0 to 255—recall that this is the value that can be stored in a byte. So we give each bulb—red, green, and blue—an intensity, and it makes that amount of light visible, which gives us the colors we want, and hence the screen you are looking at. So now you should understand what we mean by these ones and zeroes. Similarly, all images, videos, passwords, etc., are all just ones and zeroes.

Now similarly, we humans have also come up with something to represent text. We represent each character with a bunch of zeroes and ones (this is known as ASCII).

Text is just numbers too

ASCII is just a big list everybody agreed on, where every character gets a number. For example:

CharacterNumberIn binary
A6501000001
B6601000010
a9701100001
04800110000
space3200100000

So when you type Hi, your computer actually stores two bytes: 72 for H and 105 for i. Notice that even the digit 0 is not stored as 0, it's stored as 48, because here it's a character, not a number.

Same bits, different meaning

Now here is something really important. Look at 01000001. Is it the number 65? The letter A? The red part of a pixel? Well, it's all of them! The bits themselves don't know what they are. It's the program reading them that decides what they mean.

Keep this in mind, because as hackers, this is one of the most important ideas we will ever learn. A lot of real attacks happen when a program reads some bytes as something they were never supposed to be.

Bigger units

Since bytes are tiny, we use bigger units for bigger things. A kilobyte (KB) is about a thousand bytes, a megabyte (MB) is about a million bytes, and a gigabyte (GB) is about a billion bytes. So a 1 GB movie is roughly 8 billion zeroes and ones!
