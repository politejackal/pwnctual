Launch a Codespace

A Linux machine in your browser with the course tools and the pwnctual CLI pre-installed. Free GitHub accounts include monthly Codespaces hours, which is plenty for this course.

Link the CLI to your account

In the Codespace terminal run:

pwnctual login

It prints an 8-letter code. Enter it on the link page and approve. The CLI picks up your token automatically.

Solve something
pwnctual new hello-hacker
pwnctual check hello-hacker

Other commands: pwnctual list, pwnctual show <slug>, pwnctual whoami.

Access tokens

Working outside Codespaces? Create a token and run pwnctual login --token <token> --url {{ base }}.
