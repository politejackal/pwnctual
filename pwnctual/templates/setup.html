Setup · takes about 5 minutes

Set up your computer

Install Python 3

Get it free from python.org. On Windows, tick Add python.exe to PATH in the installer. Most Macs and Linux machines already have it.

Download the checker

Make a folder for the course and save pwnctual.py in it. It's a single file that only uses Python's standard library.

downloadDownload pwnctual.py
Link it to your account

Open a terminal in that folder (Terminal on macOS and Linux, PowerShell on Windows) and run:

python pwnctual.py login

It opens the link page with an 8-letter code. Approve it and the checker picks up your token automatically. On macOS and Linux, use python3 if python isn't found.

Solve something
python pwnctual.py new hello-hacker
python pwnctual.py check hello-hacker

Other commands: list, show <slug>, whoami.

Access tokens

Can't use the browser sign-in? Create a token and run python pwnctual.py login --token <token> --url {{ base }}.
