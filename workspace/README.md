# 💀 pwnctual workspace

This is your hacking box. The course tools and the `pwnctual` CLI are already installed.

```bash
pwnctual login                 # link this Codespace to your account
pwnctual list                  # see every challenge
pwnctual new hello-hacker      # create hello-hacker.py
pwnctual check hello-hacker    # run it against randomized tests
pwnctual whoami                # your rank
```

Work inside `solutions/` if you like to stay tidy: `cd solutions`.

Every `check` sends your program **fresh random input**, so hard-coded answers
won't pass. Solve a challenge to capture its flag, earn points, and climb from
**Noob** to **Ghost**.
