At the physical level, your computer's processor and memory (RAM) are made up of billions of tiny switches called transistors.

A switch has only 2 states:

toggle_offOFF(no electrical charge)= 0
toggle_onON(electrical charge present)= 1

Every single piece of data on your device, whether it is a C program, a password, or a movie, is just a massive sequence of 0s and 1s.

The Core Units of Data

  1. A Bit (A Binary Digit): A single 0 or 1, it is the smallest possible unit of our data.
  2. A Nibble: A group of 4 bits. Example: 1011.
  3. A Byte: A group of 8 bits. Example: 10110010.
shield
The Hacker's First Law of Memory: In C and modern computer architecture, 1 Byte (8 bits) is the smallest addressable unit of memory. You cannot point to a single bit in RAM; every memory address (we will come back to this) points to a full 8-bit byte.

How to Read an 8-Bit Byte

In normal everyday math (Decimal, or Base-10), each digit column goes up by a power of 10 (100, 10, 1). As you might recall from school, we are talking about the 1's place, 10's place, 100's place, and so on. Hence the name Base-10 because each digit's place is multiplied by 10.

What do you get if you instead multiply each digit's place by 2 instead of 10? Well you get binary or Base-2! In Binary (Base-2), each bit column doubles in value from right to left, as is being multiplied by 2 (128, 64, 32, 16, 8, 4, 2, 1).

So to convert a binary byte like 01000001 into a normal number, just add up the column values where a 1 is switched ON:

Bit Value (Place)1286432168421
Binary Byte01000001
  • Only the 64 column and the 1 column are turned on (1).
  • Now you add the columns which are turned on. 64 + 1 = 65.
  • So 01000001 in binary equals 65 in decimal (which also happens to be how the capital letter 'A' is stored inside a computer, its just that somebody decided that 65 in binary would mean the letter A).

If all 8 bits are turned off (00000000), the value is 0. If all 8 bits are turned on (11111111), you add 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1, which equals 255. Therefore, a single byte can hold a value anywhere from 0 to 255.
