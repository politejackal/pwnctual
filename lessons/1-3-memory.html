Fact 1: Computers Can Only Store Numbers (Not Letters)

Memory can only hold numbers (0s and 1s). It cannot draw the shape of the letter 'A' inside a memory chip.

So computer engineers created a universal chart where every key on your keyboard has a secret code number:

  • Capital 'A' = Decimal 65 = Hex 0x41
  • Capital 'B' = Decimal 66 = Hex 0x42
  • Capital 'C' = Decimal 67 = Hex 0x43

Whenever you press A on your keyboard, the computer actually writes the byte 0x41 into memory.

Fact 2: Memory Is Just One Long Row of Boxes

Imagine a C program uses 8 memory boxes in a row to do two jobs:

  • Boxes 1 to 4 hold a 4-letter Username that you type in.
  • Boxes 5 to 8 hold the 4-byte Address of the Next Screen the program should go to after you type your name (for example, our address 0x080491B6).

Before you type anything, those 8 boxes sitting side-by-side in memory look like this:

Box 1 (Name)Box 2 (Name)Box 3 (Name)Box 4 (Name)Box 5 (Next Address)Box 6 (Next Address)Box 7 (Next Address)Box 8 (Next Address)
emptyemptyemptyempty0x080x040x910xB6

If you type a normal 4-letter name like AAAA, each 'A' (0x41) fills Boxes 1 to 4, and Boxes 5 to 8 stay untouched (0x080491B6). Everything works normally.

Fact 3: C Doesn't Stop at Box 4

Here is the quirk of the C language: there is no wall between Box 4 and Box 5.

If the program asks for your 4-letter name, and you type eight 'A's (AAAAAAAA) instead of four, C does not stop you at Box 4. It blindly keeps putting 0x41 into Boxes 5, 6, 7, and 8—erasing whatever was sitting there before:

Fact 4: Why the Computer Gets Tricked

Now the program finishes taking your name and says: "Okay, let me read Boxes 5, 6, 7, and 8 to see what memory address I should jump to next."

The computer looks inside Boxes 5, 6, 7, and 8.

It doesn't know that you accidentally spilled your 'A's into those boxes. It only sees the numbers 41, 41, 41, 41.

So the computer glues those 4 boxes together and tries to jump to memory address 0x41414141.

Because 0x41414141 is not a real place in the program, the program crashes and prints an error:

Error: Tried to jump to address 0x41414141
lightbulb
Why Knowing Hex Matters Here

If you didn't know Hex, seeing 0x41414141 in an error message would look like random computer gibberish.

Because you know that 0x41 is the Hex code for 'A', seeing 0x41414141 tells you: "Wait—the four extra 'A's I typed spilled over into the 'Next Address' boxes! That means whatever I put into Boxes 5, 6, 7, and 8 controls where the program goes next."
