Now you know about binary and hex. Now here is a bridge before going to memory architecture, because everything below builds on it.

1 byte = 8 bits = exactly 2 hex digits (0x00 to 0xFF)

One more thing: computers can only store 0s and 1s.

Memory can only hold zeroes and ones. Recall the transistors: they can only be on or off. So when you type A, it cannot draw the shape of the letter ‘A’ inside the chip or anything!

So computer scientists decided to do something smart. They used a bunch of zeroes and ones to represent A, and some other bunch of zeroes and ones to represent B, and so on. Even the numbers zero and one have some code to represent them. It’s like a character-to-number map. The widely recognized mapping is called ASCII (American Standard Code for Information Interchange).

Recall you can represent binary in decimal and decimal in binary.

So now just don’t freak out when you see a bunch of ones and zeroes or a hex value mapped to some character like A, B or C. This is not something you memorize, though.
