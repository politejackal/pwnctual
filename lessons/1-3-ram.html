Now you know about binary and hex. Now here is a bridge before going to memory architecture, because everything below builds on it.

1 byte = 8 bits = exactly 2 hex digits (0x00 to 0xFF)

One more thing: computers can only store 0s and 1s.

Memory can only hold zeroes and ones. Recall the transistors: they can only be on or off. So when you type A, it cannot draw the shape of the letter ‘A’ inside the chip or anything!

So computer scientists decided to do something smart. They used a bunch of zeroes and ones to represent A, and some other bunch of zeroes and ones to represent B, and so on. Even the numbers zero and one have some code to represent them. It’s like a character-to-number map. The widely recognized mapping is called ASCII (American Standard Code for Information Interchange).

Recall you can represent binary in decimal and decimal in binary.

So now just don’t freak out when you see a bunch of ones and zeroes or a hex value mapped to some character like A, B or C. This is not something you memorize, though.

What RAM actually is: Addresses vs. Values

Now, let’s look at the RAM. Here’s a really great analogy my teacher taught me. Think of your computer’s RAM as a really really long street of houses. Like, billions of houses. Each house contains 1 byte. Simple as that.

Every house on this street has 2 completely different properties: its address and its value.

  1. The memory address (WHERE the byte is): It is literally the address of the house. In everyday life it might be something like Building 54, Street Uranus, California, USA. In computer science, this address is something like a unique bunch of zeroes and ones! Recall all we have at the end of the day is zeroes and ones! However, memory addresses are generally 64 bits long (recall what bits really are!). Writing an address out in binary would be a mess. To make this somewhat readable, humans before us decided to represent them in hex. Example: 0x7ffe16292f84
  2. The value (WHAT the byte is): This is the literal value, what’s inside the house, or the byte we are talking about. This is also represented in hex for similar reasons. Example: 0x41
